## Educational 3D illustrations

The existing part explorer offers an opt-in 3D view alongside its original 2D schematic. Three original procedural models depict a generic femoral shell, bearing insert and tibial baseplate. They use arbitrary units, approximate shapes and illustrative colors, with no manufacturer CAD, exact-model material claim, compatibility or sizing implication. Both manufacturer profiles intentionally share these illustrations. No Persona-specific or Triathlon-specific geometry is claimed. These assets are unsuitable for manufacturing, implant selection or surgical planning.

The Three.js renderer loads only after selecting **Explore in 3D**. Readers can inspect the selected part, see an exploded three-part view, drag to orbit, use keyboard-accessible rotation/zoom/reset controls and download each illustrated component as a binary glTF (`.glb`) file. Downloads contain the original mesh and educational metadata; they are generated locally without a server request. No automatic rotation or persistent animation loop is used. Switching back to 2D disposes the scene; missing WebGL or context loss restores the schematic. Existing part explanations remain available independently of graphics support.

The geometry lives in `src/lib/intelligence/knee-geometry.ts`; the viewer and renderer reuse the existing protected prototype. The original geometry is project-authored rather than copied or extracted from manufacturer assets. Three.js is pinned and served through the app without external model, texture, CDN or analytics requests. Browser verification checks both desktop and mobile rendering, keyboard controls, all three GLB exports, display toggling, context loss, unavailable WebGL and accessibility. A true product reconstruction would require an appropriately licensed and verified exact-model source.
